## Decisions

- Owner: the complaint was AltTab (⌥Tab) + pins. AltTab 11.7.1 rejects `AXFloatingWindow` and
  admits windows above level 0 only when `kAXMain`, so pins became normal-level windows (lose
  always-on-top). Rejected: per-pin "keep on top" toggle, keeping pins floating.
- Owner: Recortia joins ⌘Tab/Dock only while a window is open (rejected: always regular, a
  settings toggle).
- Owner: adopt pin Copy/Drag Out; no capture sound; Tendedero inbox mode, private fullscreen
  API, folder watching, persisted shelf, Markup handoff declined (ADR-007).
- Owner: window-open latency is the "page load" metric; editor and first-open Settings misses
  are recorded and deferred (BACKLOG FP-028). Rejected: skeleton/deferred rendering to pass the
  metric, inspector UX changes. Only remaining lever: pre-built hidden windows (needs a Sol plan
  + owner approval). Onboarding is borderline (36–66 ms) and NOT covered by the deferral.
- The shared export slot (a waiting drag blocks other exports) is pre-existing, listed in
  THREAT_MODEL residuals; not changed.

## Dead ends

- Ordering SwiftUI hosting windows offscreen in the E2E process (Settings, `PinPanel`) crashes
  with layout recursion; a `PinPanel` alive after `pins.close` also recurses. Order on-screen at
  alpha 0, or use plain windows.
- `AltTab --help` spawns a hanging second AltTab instance.
- zsh `$files` is not word-split; use `files=(${(f)"$(...)"})`. `| head` hides exit codes.
- dcg blocks `rm -rf`, variable redirect targets, and `mv` involving `~` combined with other
  commands; use a standalone `mv <path> ~/.Trash/`.
- One pt-BR run failed `capture-focus` (foreground app changed); 4 reruns passed. Hypothesis
  recorded: demoting to accessory while Recortia is active lets macOS activate another app.
