## Decisions

- Dynamic activation policy (regular only while a switchable window exists) over always-regular
  (Sol's plan) and over a settings toggle. Switchable = top-level, level `.normal` or `.modalPanel`,
  visible or minimized. Rejected: inferring from SpacePolicy flags.
- Pin export provenance: exportable only if rendered via `PinsModel.pin(session)`; export = pinned
  raster at its own size (zoom/opacity display only); drag uses the existing drag-chip flow.
- Tendedero features declined (recorded in ADR-007): inbox mode rewriting `com.apple.screencapture`
  (AGENTS.md forbids changing system settings), private `CGSCopyManagedDisplaySpaces` fullscreen
  hiding (no private frameworks), Desktop/screenshot-folder watcher, persisted shelf (no archive),
  sounds (owner said no), Markup/Preview handoff (own editor). Sol's "open-documents shelf" was
  not chosen by the owner.
- Latency: no skeleton/deferred rendering to pass the metric, no inspector UX changes; record the
  miss in FP-028. Measured medians (Debug E2E): pin 25.8 ms, onboarding 35.8, Settings reopened 6.8
  (pass); **editor 229 ms, Settings first open 105 ms (fail)**. `-O` build only ~20% faster; cost
  is SwiftUI graph build (inspector ≈150 ms: Style ~40, Presentation ~37, Redaction ~25,
  Composition ~25, Document ~22, Recognition ~12, empty grouped Form ~22; toolbar ≈55; Settings
  shortcuts tab ≈90). Only real lever left: pre-built hidden windows → a big change needing a Sol
  plan + owner approval.
- AltTab ignores custom windows under 100×50; a tiny zoomed-out pin may drop out — unverified.

## Dead ends

- Ordering SwiftUI hosting windows **offscreen** in the E2E process (`E2ESnapshot.park` +
  `orderBack`) crashes with layout recursion (`NSHostingView.updateAnimatedWindowSize`, exit 139),
  e.g. the Settings window. Also a `PinPanel` kept alive after its pin is removed from the model
  recurses. Use plain titled windows as stand-ins, release a `PinPanel` before `pins.close`, or
  order on-screen at alpha 0 (as `editor-presentation` and `window-latency` do).
- `AltTab --help` launches a second AltTab instance that hangs; don't run it.
- zsh does not word-split `$files`: `swift format lint $files` silently linted nothing. Use
  `files=(${(f)"$(...)"})`. Also `| head` hides exit codes.
- dcg blocks `rm -rf`, redirects to variable paths, and `mv` with `~` in the same command as
  other steps; use literal paths and a standalone `mv <path> ~/.Trash/`.
