## 2. Structure notes

- `Imaging/RenderEngine.swift:133` and `Imaging/AnnotationRenderer.swift:30,51,106` — **SHAPE.** A curved-arrow export can construct, stroke, and union the same path three times across preflight and draw. Reuse the operation-local layout and preserve typed failures.
- `Imaging/AnnotationRenderer.swift:42–48` and `Imaging/TextLayout.swift:97–108` — **SHAPE.** The text draw path repeats the origin, wrap-width, font-size, and style checks before layout. Consolidate them in typed text admission.
- `Imaging/ScrollStitcher.swift:173,337` — `rows + footer` makes a full-size staging array before constructing a second buffer with `Data(pixels)`. Near 40 MP, the extra array can reach 160 MB. Build the provider data directly from the two buffers.
- `Imaging/ImageStore.swift:24–27` — The single-image accessor has no caller. Batch lookup scans the entire store for every render. Look up the requested IDs inside the same actor call.
- `Imaging/DecodeContainerHeaders.swift:84,136,148` — IDAT bookkeeping has a count cap. Withheld ancillary ranges accumulate one entry per matching chunk, and the cleaned copy reserves the entire input size. Coalesce withheld ranges and reserve the retained size.
- `Imaging/TextRecognizer.swift:23,39–45` — `LanguageAvailability` and `availability(of:)` serve one test and repeat the production language mapping. The production API already has coverage for unavailable and empty requests.
- `Domain/Annotation.swift:117–127` — `outsetBounds` and its private `isArrow` helper have one test caller and no production callers.
- `Domain/DocumentSession.swift:55` — `redoLabel` has one test caller and keeps `Entry.label` on every history entry. This is separate from the previously removed `undoLabel`.
- `Domain/Document.swift:287–300` — Mask mapping builds `toDocument`, then `layer.documentBounds` rebuilds it. Reuse the transform. The inverse, finite-corner, and clipping checks are **PRIVACY** guards and should stay.
- `Domain/DocumentSession.swift:49` — `referencedAssetIDs` concatenates both history stacks before scanning them. Iterate the existing stacks and optional group directly.

The opaque-mask checks at admission and render, plus the metadata allowlist after encoding, are **PRIVACY** checks. `Imaging/ExportPipeline.swift:71–72` is the **STALENESS** decision for an asynchronous snapshot and should stay. ## 3. Open questions

- `Imaging/ScrollMatcher.swift:129–140` — Should an equally good nonzero displacement count as ambiguous once fixed bands are known? The current repeated-row test explicitly permits full-period movement to look stationary when the pixels are identical.
- `Imaging/DecodeContainerHeaders.swift:259–262` — Is late JPEG recovery intentional? Preflight accepts an EOF inside the final scan, and `DecodeImage.swift:42–46` accepts any correctly sized ImageIO result. The existing early and halfway truncation fixtures leave the late-scan behavior on macOS unverified.
- `Domain/StateMachines.swift:187–189` — Can `.cancel` arrive while a sink is still committing and can still fail? The state machine immediately records success, and its unit test expects that transition. The caller determines whether the state can produce a false success.
