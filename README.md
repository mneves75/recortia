# Recortia landing page (GitHub Pages)

Static site published from this `gh-pages` branch at https://mneves75.github.io/recortia/
(pt-BR) and https://mneves75.github.io/recortia/en/ (en-US). The app lives on `main`.

- `index.html`, `en/index.html`: generated by `_src/build.py` (one template, one string table per language).
- `assets/`: styles, script, the 15-second launch videos, and screenshots from the app's end-to-end
  runs (synthetic fixture content only).
- `_test/e2e.mjs`: Playwright + axe-core end-to-end check (needs a Chromium headless shell at the path in the
  script). After `pnpm install --frozen-lockfile` in `_test/`, `SITE_DIR=.. node _test/e2e.mjs` serves this
  branch locally under `/recortia/`, and `BASE=https://mneves75.github.io/recortia/ node _test/e2e.mjs` checks
  the live site. Screenshots and `report.json` go to `_test/out/`.

Third-party notices: `THIRD_PARTY.txt`.
