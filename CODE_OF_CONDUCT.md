# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep discussion about the work, and do not harass
anyone. Report unacceptable behavior privately through GitHub's private vulnerability reporting
on this repository (it reaches the maintainer only). Maintainers may remove content or block
participants who violate the covenant.
